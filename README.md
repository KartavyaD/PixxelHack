
# 🎯 FINSPIRE – Inspiring Students to Financial Literacy

**Live Demo:** (https://finspire.onrender.com)  

Finspire is a modern, responsive, and interactive **Financial literacy platform** targeted at students.  
It educates users about **personal finance, budgeting, saving, investments, and financial decision-making** through **gamification, AI FinBot, AI-driven insights, and interactive simulations**.

---

## 📌 Features

- **💡 Smart Budgeting Tools** – Track expenses, set goals, and manage finances efficiently.
- **🤖 AI-Powered FinBot (Insights)** – Get personalized investment and savings advice.
- **🎮 Gamified Learning** – Earn points, unlock achievements, and progress through levels.
- **📊 Expense Tracker** – Categorize and visualize your spending.
- **📅 Budget Planner** – Plan and allocate funds effectively.
- **🧠 Interactive Courses** – Learn about budgeting, investing, credit, and fintech innovations.
- **🏆 Quizzes & Rewards** – Test your knowledge and earn badges.
- **📈 Goal Progress Dashboard** – View savings goals and AI recommendations.


## 🚀 Tech Stack

**Frontend:**
- HTML5, CSS3, JavaScript (Vanilla JS or Framework)
- Responsive UI with modern CSS design
- Marquee and carousel animations for highlights
- Razorpay API (for payment simulation, if included)
